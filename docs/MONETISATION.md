# Monetisation JobFaso

## Principe central

Les chercheurs d'emploi doivent avoir acces gratuitement aux informations
essentielles : offres, concours, stages, metiers terrain, deadlines et liens
sources. Ils cherchent du travail, donc JobFaso doit gagner leur confiance avant
de leur demander de l'argent.

Le revenu doit venir surtout de :

- publicite ;
- recruteurs ;
- sponsors ;
- services optionnels ;
- formations partenaires ;
- marketplace de services ;
- donnees agregees non personnelles.

## 1. Publicite display

Objectif : monetiser le trafic sans bloquer l'acces.

Canaux :

- Google AdSense ;
- Google Ad Manager plus tard ;
- bannieres vendues directement ;
- native ads clairement marquees comme sponsorisees ;
- sponsorisation de categories.

Regles AdSense importantes :

- avoir du contenu original et utile ;
- respecter les politiques Google ;
- ne jamais encourager les clics ;
- ne jamais cliquer sur ses propres pubs ;
- ne pas creer des pages vides uniquement pour afficher des pubs ;
- separer clairement contenu et publicite ;
- ajouter mentions legales, confidentialite et contact.

AdSense Auto ads peut etre utile : un code est ajoute au site et Google place
automatiquement les annonces selon la page. Mais JobFaso ne doit pas dependre
uniquement d'AdSense, car les revenus publicitaires au debut seront souvent
modestes.

Sources officielles :

- Eligibility: https://support.google.com/adsense/answer/9724
- Auto ads: https://support.google.com/adsense/answer/9261805
- Program policies: https://support.google.com/adsense/answer/48182

## 2. Sponsoring direct

Objectif : gagner plus vite qu'AdSense avec moins de trafic.

Clients :

- ecoles de formation ;
- centres de langues ;
- fintech et mobile money ;
- operateurs telecom ;
- cabinets RH ;
- entreprises qui recrutent ;
- ONG et programmes jeunesse ;
- auto-ecoles ;
- formations IT, Excel, comptabilite, anglais, solaire, conduite.

Formats vendables :

- sponsor "Concours de la semaine" ;
- sponsor "Offres ONG" ;
- sponsor "Stages et jeunes diplomes" ;
- sponsor newsletter WhatsApp ;
- sponsor page d'accueil ;
- sponsor metier : "Devenir technicien solaire" ;
- article sponsorise clairement marque.

Prix de depart :

- 25 000 FCFA / semaine pour une petite mise en avant ;
- 100 000 FCFA / mois pour une categorie ;
- 250 000 FCFA+ pour campagne multi-canal.

## 3. Annonces recruteurs

Objectif : faire payer ceux qui ont un budget recrutement.

Gratuit :

- annonce standard verifiee ;
- lien source officiel ;
- pas de garantie de diffusion premium.

Payant :

- annonce mise en avant ;
- diffusion WhatsApp ciblee ;
- publication Facebook/LinkedIn ;
- preselection simple ;
- formulaire candidat ;
- export CSV des candidats ;
- alerte urgente.

Prix de depart :

- 10 000 FCFA annonce standard assistee ;
- 25 000 FCFA annonce mise en avant ;
- 75 000 a 150 000 FCFA campagne recrutement.

## 4. Leads recruteurs

Objectif : vendre une action qualifiee, pas seulement une publication.

Exemples :

- candidat interesse et qualifie ;
- CV filtre selon criteres ;
- appel de verification candidat ;
- shortlist de 10 profils.

Prix :

- 500 a 2 000 FCFA par lead qualifie ;
- 25 000 a 100 000 FCFA par shortlist.

Regle : demander le consentement des candidats avant transmission de donnees
personnelles.

## 5. Services candidature optionnels

Les offres restent gratuites. Les services qui economisent du temps peuvent etre
payants.

Services :

- correction CV ;
- CV ATS ;
- lettre de motivation ;
- traduction FR/EN ;
- preparation entretien ;
- verification dossier concours ;
- creation de profil LinkedIn ;
- photo CV professionnelle via partenaire local.

Prix :

- 1 000 a 3 000 FCFA service rapide IA ;
- 5 000 a 15 000 FCFA service humain + IA.

- mecanicien ;
- chauffeur ;

- technicien solaire.

Revenus :

- mise en avant ;

## 8. Newsletter et WhatsApp sponsorises

Objectif : monetiser l'audience sans fermer l'acces.

Formats :

- "Offres de la semaine presentees par..." ;
- sponsor du canal WhatsApp ;
- message sponsorise limite et clairement identifie ;
- placement dans digest email.

Regle : peu de sponsors, clairement marques, et toujours plus de contenu utile
que de publicite.

## 9. Data insights agregees

Objectif : vendre des tendances, jamais des donnees personnelles brutes.

Clients :

- cabinets RH ;
- ONG ;
- institutions ;
- ecoles ;
- investisseurs ;

Rapports :

- metiers les plus demandes ;
- villes les plus actives ;
- secteurs qui recrutent ;
- salaires indiques ;
- competences demandees ;

Prix :

## 10. API / Flux recruteurs

Objectif : vendre l'acces technique a des donnees propres.

Exemples :

- flux d'offres verifiees ;
- webhook nouvelles annonces ;
- API recherche emploi Burkina ;
- integration avec sites RH locaux.

Ce revenu vient plus tard, quand la base est propre et reconnue.

## Roadmap revenu rapide

### Jours 1 a 14

- Site gratuit.
- Canal WhatsApp.
- 100 a 300 offres/concours propres.
- Formulaire recruteur.
- Kit sponsor PDF simple.
- Vente manuelle de 3 sponsors locaux.

Objectif : premiers 50 000 a 300 000 FCFA.

### Jours 15 a 45

- AdSense si le site est pret et conforme.
- Pages SEO par categorie et ville.
- Pack annonce recruteur.
- Pack CV optionnel.
- Newsletter sponsorisee.
- 1 partenariat formation.

Objectif : revenus recurrents modestes mais reels.

### Mois 2 a 3

- Back-office moderation.
- Alertes gratuites candidats.
- Offres premium recruteurs.
- Shortlist recruteur.
- Profils artisans verifies.
- Sponsors mensuels.

Objectif : 500 000 a 2 000 000 FCFA/mois si l'audience suit.

### Mois 4 a 6

- Marketplace missions.
- Rapports data agregees.
- API/flux partenaires.
- Evenement emploi.
- Extension UEMOA.

## Scenario chiffre sain

Scenario initial, sans bloquer les chercheurs d'emploi :

- AdSense/display : 50 000 a 300 000 FCFA/mois selon trafic.
- 10 annonces recruteurs a 25 000 FCFA = 250 000 FCFA/mois.
- 3 sponsors categorie a 100 000 FCFA = 300 000 FCFA/mois.
- 100 packs CV a 2 000 FCFA = 200 000 FCFA/mois.
- 50 profils artisans a 1 500 FCFA = 75 000 FCFA/mois.

Total initial possible : 875 000 FCFA/mois avant frais.

Scenario plus fort :

- 100 000+ visiteurs/mois ;
- sponsors reguliers ;
- recruteurs actifs ;
- marketplace terrain ;
- services candidature.

Potentiel : plusieurs millions FCFA/mois, mais seulement avec contenu fiable,
distribution WhatsApp forte et execution commerciale active.

## Regles de rentabilite

1. Gratuit pour consulter les offres essentielles.
2. Payant pour gagner du temps, recruter, sponsoriser ou obtenir plus de
   visibilite.
3. Toujours marquer les contenus sponsorises.
4. Ne jamais vendre de donnees personnelles sans consentement.
5. Ne pas dependre uniquement d'AdSense.
6. Vendre directement aux entreprises le plus tot possible.
7. Garder la confiance plus importante que le revenu court terme.
