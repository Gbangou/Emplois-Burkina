# Kit sponsor JobFaso

## Positionnement

JobFaso est un media emploi et opportunites au Burkina Faso. Le site aide les
candidats a consulter gratuitement les offres, concours, stages et missions,
puis permet aux annonceurs de toucher une audience active.

## Audience cible

- Jeunes diplomes.
- Candidats aux concours.
- Professionnels bureau : IT, banque, finance, administration, ONG.
- Professionnels terrain : macon, plombier, mecanicien, chauffeur, technicien.
- Recruteurs et cabinets RH.
- Ecoles et centres de formation.

## Formats commerciaux

### Annonce mise en avant

Prix de lancement : 25 000 FCFA.

Inclus :

- publication prioritaire ;
- badge "mise en avant" ;
- diffusion WhatsApp ;
- visibilite page accueil pendant une periode limitee.

### Sponsor categorie

Prix de lancement : 100 000 FCFA / mois.

Categories :

- concours ;
- ONG ;
- stages ;
- IT ;
- finance ;
- metiers terrain ;
- formations.

### Campagne recrutement

Prix de lancement : 150 000 FCFA+.

Inclus :

- page de campagne ;
- formulaire candidature ;
- tri de base ;
- export candidats ;
- diffusion WhatsApp et reseaux.

### Formation partenaire

Modele :

- commission par inscription ;
- forfait de visibilite ;
- coupon tracking.

### Newsletter / WhatsApp sponsorise

Prix de lancement : 25 000 a 75 000 FCFA par envoi selon audience.

Regle :

- contenu sponsorise clairement marque ;
- frequence limitee ;
- message utile pour l'audience.

## Promesse commerciale

JobFaso ne vend pas seulement de l'affichage. JobFaso vend l'acces a des
personnes qui cherchent activement un emploi, une formation, un concours ou une
mission.
